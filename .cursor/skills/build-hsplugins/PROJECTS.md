## Build Commands Quick Reference

```powershell
# Restore packages first (if needed)
nuget restore HSPlugins.sln

# Build specific project
dotnet build "Timeline.HS2/Timeline.HS2.csproj" -c Release

# Build multi-config project for specific platform
dotnet build "HSPE/HSPE.csproj" -c HS2

# Build all projects for a platform
dotnet build HSPlugins.sln -c HS2
```
